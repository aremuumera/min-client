# System prompt for AI coding assistants (MINMEG)

Use the tokens in design.md as the single source of truth. Light mode only — no dark mode. No shadows (no box-shadow, no shadow-* classes). No colours outside the palette: brand green #1e8742 (white text), brand dark #0a1f1a (text, sidebar, overlays at 70%), red/amber for errors/warnings only. Euclid Circular A everywhere. Design every component for mobile, tablet and desktop, with 44px touch targets and safe overflow. Reuse src/components/ui; create a reusable component when one is missing.
